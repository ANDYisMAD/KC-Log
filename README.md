# KC Log (RuneLite plugin)

KC Log tracks NPC kill counts reported through RuneLite's NPC loot event and displays them in a sidebar.

Features:

* **All time** — saved kill totals by NPC name.
* **Today** — kill totals for the current local calendar day.
* **Search** — filter the displayed NPC list by name.
* **Per-NPC reset** — right-click a row to reset that NPC's saved totals.
* **Reset all** — clear all saved totals after confirmation.
* **Optional chat message** — show the updated count when a tracked NPC loot event is received.
* **Daily history** — configure how many days of daily counts to retain (default 30).

Counts are stored using RuneLite's per-profile configuration.
